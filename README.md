# APP2000_G16_25


Github Repo for APP2000 Gruppe 16

Felles nettside for frisbeegolf i Norge. De vil tilby nye spillere veiledning til sporten og ha mulighet til at spillere kunne lett finne fram til og på baner, samt ha mulighet til å lagre resultat og poengsum. Og mulighet til å laste det opp til en åpen tavle som har en high score per bane. Samt registrere klubber.
